## What I've been working on

### [Procedural Map Generator](https://github.com/reueligbokwe90-droid/Procedural-Map-Generator)
A dungeon generator in Python. It uses binary space partitioning (BSP) to split a map into zones, places a room in each one, then connects them with corridors by walking the partition tree depth-first. A pygame visualiser lets you generate new maps on demand.

It was the first project I really enjoyed, because I was building something I thought was cool. It taught me how BSP trees work, how to traverse them recursively, and how to pass state up and down a recursion cleanly.
